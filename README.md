# ارسال‌یار v2.0 — گزارش‌گیری کامل ارسال

این نسخه ادامه v1.9 است و بخش گزارش ارسال را حرفه‌ای‌تر می‌کند.

## امکانات جدید
- گزارش تفکیک‌شده موفق / ناموفق
- نمایش پیام‌رسان، مقصد، متن پیام، زمان و نوع ارسال
- تشخیص ارسال مستقیم در گزارش
- فیلتر بر اساس پیام‌رسان
- فیلتر بر اساس وضعیت
- نمایش آمار تعداد کل، موفق و ناموفق
- اشتراک‌گذاری متن گزارش از داخل اندروید
- پاک‌کردن کامل گزارش‌های محلی با تأیید

## نکته
گزارش فعلی روی خود دستگاه ذخیره می‌شود و از SendLogStore استفاده می‌کند. برای گزارش مرکزی چنددستگاهی، مرحله بعد می‌تواند ثبت لاگ‌ها روی سرور و اتصال آنها به حساب کاربری باشد.

## v2.2 - branding and support
- Branding text: «طراحی توسط گروه A.P» in the app and admin panel.
- Support phone: 09372544666 with tap-to-call.
- Online support chat: user can send messages in-app; admin can view/reply/close conversations from the admin panel.
- Support chat uses short polling on the Android client for near-real-time replies.
- Support data is stored server-side in `support_threads` and `support_messages`.


## v2.3 - امنیت و ضدکپی‌برداری
- طراحی امنیتی با فرض قابل استخراج بودن APK؛ هیچ secret حساس داخل کلاینت قرار نمی‌گیرد.
- منطق اشتراک، پرداخت، سهمیه و دسترسی مدیر در سرور authoritative است.
- R8/ProGuard در Release فعال شده است.
- توکن در Android Keystore/EncryptedSharedPreferences ذخیره می‌شود.
- لاگ HTTP در Release خاموش است.
- Release فقط برای HTTPS تنظیم شده؛ HTTP صرفاً در Debug برای توسعه محلی مجاز است.
- rate limit برای API، ورود، ثبت‌نام و پشتیبانی.
- محدودیت اندازه درخواست و security headers.
- ثبت گزارش ارسال با local_id یکتا و بررسی مالکیت message_id.
- راهنمای کامل تهدید و استقرار در SECURITY.md و تنظیمات نمونه در server/.env.example.

### نکته ضدکپی‌برداری
هیچ APK اندرویدی صددرصد غیرقابل استخراج نیست. هدف v2.3 این است که کپی APK به‌تنهایی برای ساخت یک سرویس قابل استفاده نباشد؛ بخش ارزشمند و حساس برنامه باید در API سرور و سیستم اشتراک باقی بماند.

## v2.5 - ضدکپی و اتصال نصب
- بررسی امضای APK در Release (با fingerprint قابل تنظیم در CI).
- شناسه یکتای نصب با ذخیره‌سازی رمزنگاری‌شده.
- Device binding سمت سرور و سقف دستگاه قابل تنظیم.
- امکان لغو دستگاه از پنل مدیر.
- خروج از حساب، نصب جاری را revoke می‌کند.
- Play Integrity هنوز لایه مرحله انتشار نهایی است و باید پس از تنظیم Google Play Console فعال شود.

## v2.7 - پیام رسانه‌ای پیشرفته
- هر متن در یک مجموعه پیام می‌تواند تا ۱۰ عکس مستقل داشته باشد.
- عکس‌ها برای هر متن جداگانه انتخاب/حذف می‌شوند و همه متن‌ها مجبور به استفاده از یک عکس مشترک نیستند.
- زمان‌بندی محلی، image URIs هر متن را حفظ می‌کند.
- ارسال چندعکس از مسیر ACTION_SEND_MULTIPLE انجام می‌شود؛ رفتار نهایی و نیاز به تأیید کاربر به نسخه و رابط هر پیام‌رسان وابسته است.
- در سرور، image_uris به صورت JSON metadata ذخیره می‌شود و فایل واقعی روی دستگاه کاربر باقی می‌ماند.
